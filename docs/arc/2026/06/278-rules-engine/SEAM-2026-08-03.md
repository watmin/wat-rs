## The rulings you inherit — do NOT re-litigate

1. **Peers are RESOURCES, not pure.** A thing holding a resource is a **struct**, never a record.
2. **The budget is a property of the WIRE.** The axis is **shared-memory vs a wire**, NOT
   thread-vs-process — and `PeerTx::{Thread,Socket}` already carries it under the right name. The
   rule is *"applies wherever `send_wire` is the path"*, which forward-covers remote loci.
   The thread tier **never encodes at all**; a byte budget there measures a thing that does not exist.

   *declared contract*; bad clients are still dismissed by the server. Belt and braces.
4. **Blocking is BACKPRESSURE, not a bug.** Make a blocked write *wakeable*; never make it return early.
5. **The 512 KiB-frame-over-64 KiB-pipe mismatch is DELIBERATE** — a layer-7/layer-2 decoupling so
