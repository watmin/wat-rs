## Things that are TRUE and easy to get wrong

- **A JIT is not superior to static compilation.** I said that and had to retract it. If the JVM beats
  us we are doing MORE WORK. What C2 buys Clojure is profile-guided devirtualisation of megamorphic
  `IFn.invoke` dispatch — a problem Rust does not have. Clara's per-fact cost falls with size because
  the harness's 3 warmup fires give the inner loop far more trips at large N, not because JITs win.
- **Clara IS incremental** (`engine.cljc:1014`): it stores the reduced value per binding group and
  folds new elements onto it via `:combine-fn`. Invisible in a single-fire benchmark; decisive for
  streaming. **And the doctrine already permits us the same** — `PVRITAS VERVM, NON CELERITATEM`:
  purity is the correctness doctrine, incremental TM is allowed as a performance layer behind the
  pure boundary. It is unbuilt work, not a forbidden move.
- **"Biggest line item" ≠ "the differentiating line item."** I chased `alpha_match_inner` because it
  was biggest — but alpha runs on every axis and we win six of seven, so it cannot be the loss. The
  builder caught it. Ask which component only the LOSING axis exercises.
- **Never run a grid axis or probe without the memory guard**, ladder climbed upward. A timeout bounds
  time, not RAM — that is how the workstation died.
- **Do not run cargo while a rider is live.** I manufactured a phantom test failure that way, then
  attributed a 3.1× phase swing to allocation when it was my own contention.
