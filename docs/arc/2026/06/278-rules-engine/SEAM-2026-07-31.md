## ★ THE HEADLINE — three quadratics found and killed, none in the engine

A8 (node-share) was the one grid cell Clara won. Chasing it led **out of the rete engine entirely**
and into the collections layer. The engine was never the problem.

```
                        before        after
node-share M=4000
  derive               11,697.4ms     110.7ms     106×
  whole-process wall       11.91s       0.63s      19×
query-by-type-string   12,475.6ms      29.3ms     426×
```

Every phase of that workload — build, compile, seed, fire, derive — is **linear for the first
time.** Three defects, in order of discovery:

1. **The compiler duplicated EDGES** (`9fa20e00`). `find-or-mint-*` shared nodes correctly, but
   `network-add-child` conj'd unconditionally, so N rules wired N identical edges into a shared
   node. The fire loop iterates edges → `RootJoin = M·N`, `HashJoin = M·N³`. At N=20/M=500 that is
   4,000,000 tokens — **the >4 GiB that killed the workstation, accounted for exactly.** Fixed by
   making `network-add-child` idempotent.
2. **`seqable->stream` walked via `rest`** (`61211301`). `rest` on any eager container rebuilds it,
   so the eager→lazy converter was O(n²) — and six verbs delegate through it. Now native.
3. **`filter` hand-rolled the same walk** (`ac26d172`). Now native. This is the one
   `query-by-type-string` calls, so it closed the A8 derive quadratic outright.
