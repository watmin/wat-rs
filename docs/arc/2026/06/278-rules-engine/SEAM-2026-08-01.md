## ★ THE FINDING — the one that reframes the whole perf axis

`stream->vec` drained a Stream with **one `conj` per element**, and `vector_conj_inner` does
`(**xs).clone()` on `Value::Vec(Arc<Vec<Value>>)` — a **full copy of the accumulator, per element**.
So `(into [] (map f coll))`, the language's standard materializer, was **O(n²)**. 101 call sites,
plus `mapv`/`filterv`/`doall` and every grid axis's derive.

Fixed (`e12acc8d`): drain into a PersistentVector (rpds, structural sharing — linear), materialize
**once** via a new native `:wat::core::Vector/extend`, reached through `into`'s new
`(Vector, PersistentVector)` clause.

```
n=40000   stream->vec drain   8111.72ms → 122.47ms   (66x)   8x n was 114x time; now 8.9x — LINEAR
derive    map 5059.5ms → 609.2ms (8.3x)              total derive 5320ms → 865ms
fanout [40000]  wall 6433ms → 1322ms (4.9x)          wall-ratio 0.73 :clara → 3.32 :us
```
