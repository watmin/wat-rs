## Why (builder, 2026-09-27: D3)

wat has two readers:

- **`wat-edn`**: EDN **data** (`:wat::edn::read`). Arc 218 made it trustworthy with a differential ward, run until
  no new cases turned up: **`crates/wat-edn/tests/clj_oracle_parity.rs`**, corpus
  `crates/wat-edn/tests/clj_oracle/corpus.txt` (221 cases, generated by `generate_corpus.py`), answers baked from real
  `clojure.edn` in `golden.txt` (`regen.clj`).
- **`wat-reader`** (`crates/wat-reader`): wat's **source** reader. The ward's own header states the design: *"Clojure-dialect
  **code** reader: EDN plus wat's reader macros."* So the intent is that it be a superset of EDN.

**Nobody has pointed the oracle at `wat-reader`.** The orchestrator measured on 2026-09-27 that, in source,
`#inst "…"`, `#uuid "…"`, `#u/T 7` and `#wat.core/Span {…}` each read as **two forms**, and `#_ 5 6` as three. Only
`#{…}` is handled. `:wat::edn::read` reads all of those correctly. The builder finds the source reader's gap
unacceptable. This stone produces the complete, oracle-checked list of divergences, so the 251/300 ordering is decided
from data.

## Measure

1. **Run every corpus case through `wat-reader`** (its own parse entry point; say which), beside the baked `golden.txt`
   answer and `wat-edn`'s answer. For each case record `clj`, `wat-edn`, and `wat-reader`, each as OK / ERR, and for OK,
   whether the **value/form** agrees with `clj`'s. Agreement means **structural**, not text: compare parsed structure.
   Say how you compared forms against `clj`'s printed golden.
2. **Class every case where `wat-reader` disagrees with `clj`:**
   - **(K)** `::` / keyword rules (251's flip);
   - **(H)** `#` dispatch: tagged literals, `#_`, `#inst`, `#uuid`, user tags (arc 300);
   - **(M)** wat's deliberate reader macros (quote/quasiquote and so on) where the source dialect is intentionally
     wider than EDN: exempt, with the reason;
   - **(O)** other: numbers, strings, chars, symbols, maps/sets (duplicates), whitespace, comments.

   Give counts per class and the full list with the input.
3. **The reverse direction:** constructs `wat-reader` accepts that `clj` refuses. Class them the same way.
4. **What each class needs, sized.** For (H) especially: where would a tagged literal live in `WatAST` (no node exists?),
   who resolves the tag (the reader cannot know user types; `#u/T 7` needs the type registry), and what `#_` needs. For
   (K): how it relates to the 251.8d converted floor. **Do not design a fix** (STOP-1); report the shape and its
   measured consequences.
